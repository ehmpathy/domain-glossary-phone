# 🌙 dream: the achiever's asks inventory must not put raw peer prose into a tracked file

- kind: reseed
- owner: ehmpathy/rhachet-roles-bhrain (role=achiever)
- caught 2026-11-17

## .the cue that fired

a route commit failed: `.husky/check.timestamps.sh` (declapract husky practice) refused `$route/.goals/asks.inventory.jsonl`, because a peer message archived there verbatim held two clock times.

## .the gap, precisely

- the achiever hook appends each peer message, verbatim, to `$route/.goals/asks.inventory.jsonl`, and the route dir is tracked
- the husky timestamp hook scans every staged non-`.ts`/`.sh` file, takes no exemption, and is locked by `check.timestamps.lock.sh`
- `goal.guard` forbids direct access to `.goals/`, so a driver cannot mask the line
- ⇒ any peer message with a clock time halts every later commit in a repo that holds both practices, and no driver lever clears it

## .the shape of the fix

either:
- mask clock times (and other timestamp forms the husky hook matches) at write time, e.g. `[time]`, before the line lands in the inventory, or
- keep the raw inventory untracked (gitignore it inside `.goals/`) and track only a masked or hashed form

clamp: a peer message that holds a clock time (hour, colon, minute) → the inventory line passes `.husky/check.timestamps.sh`

## .why it is not done in this round

the achiever lives in another repo; this route needs a human to mask the one line or untrack the file.
